# 诗词射覆

React + TypeScript 静态网页游戏，支持单人与系统对战、两人同屏接龙。仅支持唐宋诗词。默认单人模式、系统先出题、5 分胜出、不限时、分级提示开启。

## 启动与构建

需要 Node.js 20.19+（20 系列）或 22.12+，以及 pnpm。标准安装、构建和运行不需要 SQLite，不下载原始诗词库。

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

打开终端显示的地址，默认 `http://127.0.0.1:5173/`。网页应由 HTTP 服务打开，不直接双击源码 `index.html`。

```powershell
pnpm seed:check
pnpm test
pnpm build
pnpm preview
```

`pnpm build` 先验证轻量题池，然后生成 `dist/`。发布时上传整个 `dist/`，任何普通静态托管均可提供页面；游戏不需要 `/api/poetry` 或常驻 Node.js 后端。部署到子路径时用 `pnpm build -- --base=/子路径/`，保留全部静态资源。详见 [部署说明](docs/deployment.md)。

## 玩法

出题者给出上一句、目标字数和指定汉字。指定字不能出现在上一句中。新句须满足字数、包含指定字、与上一句有共同汉字，并能从内置题池、缓存作品或搜韵中核实为唐宋诗词原句。标点、空格不计字数，繁简体互通；参考答案不是唯一答案。

答对得 1 分，答句成为下一轮起点并轮换出题者。揭晓参考答案或超时视为失败，不计分，原出题者重新出题。揭晓和两级提示使用出题时保存的答案与全诗，无需再次联网。一级提示给朝代和作者，二级补充题名。

“轻松 / 标准 / 挑战”控制系统答题成功率：55% / 72% / 90%，不改变题目条件。五字、七字题出现机会较高，所有目标字数均在设置范围内。

“常见诗词优先”从内置题池及缓存作品选择可解题目，必要时联网补充；“在线扩展选句”按常见关键字和上一句共同字查询搜韵，不代表对搜韵全库均匀随机。在线候选不可用时可回退内置题池，但续题始终保留上一句。

## 查询与离线

轻量题池包含 9,615 条常见诗句和 1,246 首完整作品，JSON 约 1.87 MB。整库已去除，不会加载约 214 MB 的旧题库分片。

其他答案通过 `https://api.sou-yun.cn/open/Poem` 直接检索。只按完整诗句匹配，不将注释、关键词局部匹配或非唐宋作品判为正确。操作最多 15 秒、六次请求，全站页面内最多两个并发请求。分页未查完、接口异常和断网均表示查询未完成，不表示答案不存在。

判题等待暂停计时；失败后保存输入及剩余时间，选择重试或继续。完整查询未找到时，双人模式允许双方填写出处并复核；单人模式可修改答案或揭晓。系统查询失败不会被算作答错。

已打开的页面在断网时仍可使用内置和缓存作品。题池没有 12、13、15 字句；不能找到合法接龙答案时，会提示联网重试或结束后调整设置，不自动改变题目、不记失败。本项目不承诺断网后首次打开或离线重新加载网页，静态资源需由托管或浏览器缓存提供。

## 存档、全诗与繁简体

localStorage 保存当前对局；IndexedDB 保存历史，以及最多 500 首在线查询成功的作品。查询缓存按最近使用淘汰，存储不可用时退回内存。查询失败或未找到不进入缓存。

查询期间刷新后恢复为暂停，可重试或继续，不重复加分。旧存档保留比分、记录及输入；缺少参考答案的旧题暂停补齐后才能继续。诗句按繁简归一化文本去重，来源不同也不能重复得分。

点击出处查看全诗。出题时的参考答案与完整作品随对局保存；旧历史出处可按诗句重新在线检索。结算可导出文本。清除站点数据会删除本机存档和缓存。

顶部“繁體 / 简体”切换诗句、线索、出处、全诗及未提交输入；两种字形使用相同判题规则。用户提供的规则海报保持原图字形。

## 来源与维护

内置题池来自 [chinese-poetry/chinese-poetry](https://github.com/chinese-poetry/chinese-poetry)，固定提交 `b8594f81a89752241442f2ce267d6f66f96704ee`，MIT 许可。从原有数据库中导出了熟悉度标记大于零的去重诗句及完整作品；熟悉度来源于选本和作品标签，不是实时人气排名。原文件、作品索引与熟悉度保留在 JSON 中，`data/source-manifest.json` 保存固定来源校验值，`data/corpus-corrections.json` 保存历史勘误。

轻量 JSON 是版本化源数据；维护时更新诗句及对应完整作品，并同步 `seed-manifest.json` 的数量、大小和 SHA-256。`scripts/validate-seed.mjs` 验证去重、字数、作品关联和校验值，不联网、不使用数据库。许可文本位于 `public/corpus/LICENSE.txt`。

搜韵数据由在线接口按需取得，标注为搜韵来源，不套用内置题池的 MIT 许可。公开调用资料及尚未确认的限制见部署说明。

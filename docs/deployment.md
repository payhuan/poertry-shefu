# 静态部署与在线检索验证

## 发布内容

执行 `pnpm install --frozen-lockfile`、`pnpm test`、`pnpm build`，将整个 `dist/` 上传到静态托管。根目录发布使用默认 base；子目录部署需用 `pnpm build -- --base=/子目录/`。HTML、JS、CSS、规则海报和 `corpus/seed*.json` 均需保留。不要部署源码 `index.html`。

没有服务器端接口，没有 SQLite 文件或题库分片，没有运行时环境变量、密钥或 `/api/poetry`。网页直接向搜韵发送简单 GET 请求。

## 平台网络限制

页面的 Content-Security-Policy 若限制 `connect-src`，需允许 `https://api.sou-yun.cn`；平台的网络沙盒也需允许该域名。页面代码不能绕过托管平台的限制。接口响应已实测包含 `Access-Control-Allow-Origin: *`，但这不代表每个平台的页面策略都允许调用。

平台阻止查询时，内置和缓存诗词仍可玩，其他答案保持待核实，不误判为错。控制台或网络面板显示的 CSP、跨域或接口错误需保留用于部署诊断。

## 正式地址验收

目前用户仅提供了超喵平台首页 `https://v2.zcat.cn/`，没有游戏正式发布 URL，因此正式平台验收待完成。

1. 无预览后台参与，在正式地址打开新对局，确认系统可出题，两级提示及揭晓可用。
2. 在判题时使用不在轻量题池中的唐宋原句，确认请求访问搜韵、成功响应并按完整诗句匹配。不能仅用本地命中证明在线功能可用。
3. 查看该在线作品全诗；切换繁体再次作答，测试非唐宋作品不能通过。
4. 模拟断网，确认本地作品仍可用、未知答案保留并暂停；恢复联网后重试，不重复计分。
5. 查询进行中刷新，确认恢复为暂停、旧响应不加分；关闭预览后用另一设备重新访问正式地址。
6. 使用手机尺寸，检查按钮、弹窗、滚动及规则图片。

## 接口资料和使用范围

实测接口为 `https://api.sou-yun.cn/open/Poem`。查询参数：`key`、`dynasty=7/8`、`scope=3`、`jsonType=true`、从零开始的 `pageNo`。按作品 ID 查询只提供 `key` 和 `jsonType`。实际空检索会返回 JSON `null`；ID 查询会返回 `Count=0, PageSize=0` 但仍包含作品，因此按具体响应分别解析。

[上海图书馆公开接口文档](https://opendata.library.sh.cn/2022/download/opendata/2022/%E6%90%9C%E9%9F%B5%E5%BC%80%E6%94%BE%E6%8E%A5%E5%8F%A3%E8%AF%B4%E6%98%8E%E6%96%87%E6%A1%A3.pdf)说明了诗词查询参数与返回字段；[官方培训资料入口](https://opendata.library.sh.cn/docs/)列出搜韵提供的开放接口材料。文档中的旧 `.com` 域名本次无法解析，当前实测使用 `.cn` 域名。

这些资料来自开放数据活动。当前长期调用配额、商业使用授权、持续可用性及缓存许可未从公开资料中得到明确确认，不能将“当前能访问”视作无限调用或永久服务承诺。公开运营或商业发布前需向搜韵确认适用条件；没有发现明确许可时不宣称已获授权。

实现只按玩家操作调用公开接口，不抓取网页、不批量下载全库、不绕过限流；缓存最多 500 首，不保存注释。HTTP 429、网络失败、异常响应与分页未完成显示原因并允许重试。若接口明确不允许用途，关闭在线扩展，保留已有内置题池玩法，不引入隐蔽代理。
